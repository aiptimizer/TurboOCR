# Compiled ONLY by turbo_ocr_gpu under USE_CPU_ONLY=OFF, which no configure on
# a non-CUDA machine and no CI job can parse (every ci.yml configure passes
# -DUSE_CPU_ONLY=ON). Most of the includes that reach these headers from
# elsewhere sit inside `#ifndef USE_CPU_ONLY`, and check.sh compiles with NO
# -DUSE_CPU_ONLY — so this is the ONLY thing anywhere that type-checks the
# guarded branch. Without these lines a wrong path here gives a green local
# build and a broken NVIDIA image.
